# HAK Smart Filter

Bộ lọc dữ liệu dùng chung cho các ứng dụng HAK.

## Phạm vi dự kiến
- Tìm kiếm không dấu, lọc nhanh, lọc nâng cao, khoảng ngày.
- Chọn nhiều giá trị, điều kiện dạng chip, lưu và áp dụng bộ lọc.
- Bộ lọc không được tự thay đổi dữ liệu nghiệp vụ hoặc kỳ lương toàn ứng dụng.
